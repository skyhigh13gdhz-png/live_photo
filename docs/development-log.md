# 开发验证记录

## 2026-09-14：所见即所得预览与形变配置

### 目的

修复 SwiftUI 近似预览与真实导出不一致导致的露背景问题，补齐形变效果，并按“类型 → 具体效果 → 可选高级参数”重构交互。

### 改动点

- 一级选择：运镜、形变、组合、随机。
- 二级选择：7 种运镜和 5 种形变按当前类型按需展示。
- 三级设置：高级参数开关默认关闭，开启后才显示时长、运镜强度和形变强度。
- 预览改为 15fps 的 Core Image 低分辨率逐帧渲染，与 1080 × 1920 导出共用同一渲染器和参数。
- 新增纵向伸缩、横向伸缩、仿射倾斜、轻微侧倾和镜头呼吸。
- 形变前预留安全放大区，透明素材先合成白色底，最后统一裁切。
- 随机模式为每张照片独立选取运镜和形变组合。

### 验证结果

- iOS Simulator 编译：通过。
- XCTest：4 项全部通过。
- 35 种运镜×形变组合，分别在首帧、中帧、末帧进行实际像素渲染；四角色彩和 Alpha 校验通过，未露出黑色、白色或透明背景。
- 完整 Live Photo JPEG/MOV 配对资源生成与校验：通过。

### 潜在风险

- 镜头呼吸当前使用 Core Image 径向形变近似旧版 FFmpeg lens correction，强度感知需真机校准。
- 15fps 预览优先保证几何一致性；导出仍为 30fps，两者流畅度不同。

## 2026-09-14：真机窄屏布局修复

### 目的

修复多选照片后预览、长文案和参数卡片撑宽页面，造成配置被裁切且不可读的问题。

### 改动点

- 将预览区高度收紧到 220pt，缩略图收紧到 44 × 58pt。
- 选图文案改为短文案，所有根容器强制限定在屏幕宽度内。
- 7 种运镜改为 4 列按钮，全部直接展示，选中态用蓝色标识。
- 时长和强度均显示实时数值、滑杆及两端含义。
- 生成按钮固定在底部安全区，配置内容仍可独立滚动。

### 验证结果

- iPhone 17 Pro / iOS 26.5 模拟器注入 4 张测试图后完成截图检查。
- 预览、缩略图、选图、7 种效果、时长数值、强度数值和底部生成按钮均未横向裁切。
- 视觉测试使用的 Debug 测试数据已在验收后移除，未进入产品代码。

## 2026-09-14：批量生成与可配置运镜

### 目的

将真机验证通过的单图推近原型升级为可用的批处理工具。

### 改动点

- PhotosPicker 支持最多 20 张有序多选，并提供缩略图切换预览。
- 新增推近、拉远、左移、右移、上移、下移和斜向 7 种运镜。
- 开放 1.5–5.0 秒时长和 2%–20% 幅度配置，预览与导出共用同一配置。
- 批量任务逐张渲染与保存，显示单张和整体进度，单张失败不中断后续任务。
- 保留 Xcode 自动生成的 Personal Team 签名配置。

### 验证结果

- iOS Simulator 通用目标编译：通过。
- XCTest：4 项通过，包括完整 Live Photo 配对资源生成与校验。
- 7 种运镜在最大幅度的起点、中点、终点输出范围检查：通过。

### 潜在风险

- 批量生成采用串行方式以控制内存和发热，20 张在高时长设置下需要较长时间。
- 位移预览与 Core Image 导出的像素级路径不同，仍需真机逐效果视觉验收。

## 2026-09-13：Phase 0 工程骨架

### 目的

建立可运行的原生 iOS 工程，验证 SwiftUI、Core Image、AVFoundation、ImageIO 和 PhotoKit 的最小集成路径。

### 改动点

- 创建 `LivePhotoApp.xcodeproj`，最低部署版本 iOS 17。
- 建立选图、9:16 预览、生成进度和保存结果界面。
- 实现 1080 × 1920、3 秒、30fps 的稳定推近渲染。
- 使用 `AVAssetWriter` 直接生成 H.264 MOV。
- 写入 JPEG/MOV Live Photo 配对标识和静态帧时间元数据。
- 使用 `PHAssetCreationRequest` 保存 `.photo + .pairedVideo`。
- 添加稳定推近曲线端点单元测试。

### 验证结果

- iOS 26.5 Simulator Debug build：通过。
- iPhone 17 Pro / iOS 26.5 Simulator 安装与启动：通过。
- 模拟器首屏视觉检查：通过。
- XCTest：通过。
- arm64 generic iOS Debug build（关闭签名）：通过。

### 未完成验证

- 模拟器无法代替真实“照片”App 对 Live Photo 配对资源的最终兼容性验收。
- 需要配置 Apple Developer Team，在真实 iPhone 上确认保存后显示 LIVE 标志并可长按播放。
- 当前只实现“稳定推近”，其余 6 种运镜和 5 种形变尚未迁移。

### 潜在风险

- Live Photo 手工配对元数据不是 Apple 完整公开规范，真机闭环仍是 Phase 0 的硬门槛。
- 当前中点 JPEG 与 MOV 共用渲染公式；已校验 metadata 轨存在，后续还需深入解析 marker 的具体值和时间范围。

## 2026-09-13：配对资源校验

### 目的

在请求照片权限和写入系统图库前阻断空文件、尺寸错误、配对标识不一致或 metadata 轨缺失的成品。

### 改动点

- 新增 `LivePhotoValidator`。
- 校验 JPEG/MOV 存在且非空。
- 校验 JPEG 为 1080 × 1920，MakerApple `17` 与任务 UUID 一致。
- 校验 MOV 视频轨尺寸、QuickTime content identifier 和 metadata 轨。
- `PhotoLibrarySaver` 在请求权限前强制执行校验。
- 新增完整生成一组 90 帧配对资源的模拟器集成测试。

### 验证结果

- iPhone 17 Pro / iOS 26.5 Simulator XCTest：2 项通过。
- 实际生成与校验集成测试：通过，约 3.0 秒。
- 该测试不写入系统照片库，也不能替代真实 iPhone 的 LIVE 标志验收。
