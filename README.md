# live_photo
使用静态图生成视频（live图）的工具

Mac Live Photo 随机组合批量生成工具 v1.0

功能：
- 从已确认的35种『7种运镜 × 5种形变』中随机选择。
- 默认每张静态图生成2个视频。
- 同一张图抽到的组合不会重复。
- 纵向形变使用v0.2的亚像素防抖实现。

使用：
1. 将待处理图片放到同一个文件夹。
2. 解压工具。FFmpeg已经安装过就不要再运行『首次安装.command』。
3. 右键打开『开始批量随机生成.command』。
4. 选择图片文件夹。
5. 生成完成后，输出文件夹会自动打开。

调整每张生成数量：
用『文本编辑』打开『批量生成参数.conf』，修改：
VIDEOS_PER_IMAGE=2

可设为1～35。例如改为3，每张图会生成3条不重复的随机组合视频。

输出文件名会记录：
原图名 + 形变名 + 运镜名

注意：
- 这里的『随机』是在35个已验证组合中抽取，不会随机改参数。
- 每张图的组合不重复，不同图片之间允许抽到相同组合。
- 图片越多、VIDEOS_PER_IMAGE越大，处理时间越长。
- 原图不会被修改或删除。
