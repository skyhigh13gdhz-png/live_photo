# live_photo

Mac 本地批量静态图微动视频工具。

它会从 **7 种运镜 × 5 种轻微形变 = 35 种组合**中随机抽取效果，将一个文件夹中的静态图片批量转换成 1080 × 1920 的短视频。默认每张图片生成 2 条，同一张图片不会抽到重复组合。

> [!IMPORTANT]
> 本工具输出的是 H.264 MP4 视频，不是苹果原生的 HEIC + MOV 配对 Live Photo。它适合继续导入剪映、照片 App 或其他工具，截取/转换为实况素材。

## 能做什么

- 批量处理一个文件夹中的 JPG、JPEG、PNG、HEIC 和 WebP 图片。
- 默认每张图片生成 2 条视频，可配置为 1～35 条。
- 每张图片的组合不重复；不同图片之间允许抽到相同组合。
- 输出文件名记录原图名、形变名称和运镜名称，方便筛选。
- 纵向形变使用亚像素透视插值，避免旧版整数缩放造成的周期性抖动。
- 不修改或删除原图。
- 只计算随机抽中的效果，不会先生成全部 35 条再删除未选结果。

## 不能做什么

- 不会生成眨眼、呼吸、手指活动、头发摆动等真实人物动作。
- 不会改变照片内容或重新绘制人物、商品和背景。
- 不会直接输出苹果原生 Live Photo 文件对。
- 当前版本只适配 macOS，不支持直接在 Windows 上运行。

## 系统要求

- macOS
- 网络连接：仅首次安装 Homebrew/FFmpeg 时需要
- FFmpeg
- 建议预留足够磁盘空间；图片数量和每图生成数量越大，耗时和输出文件越多

## 下载与安装

### 方法一：下载 ZIP

1. 在仓库页面点击 **Code → Download ZIP**。
2. 解压完整文件夹，不要只单独拖出某一个脚本。
3. 首次使用时，右键打开「首次安装.command」。
4. 安装完成后，右键打开「开始批量随机生成.command」。

### 方法二：使用 Git

```bash
git clone https://github.com/skyhigh13gdhz-png/live_photo.git
cd live_photo
chmod +x 首次安装.command 开始批量随机生成.command
```

首次安装：

```bash
./首次安装.command
```

以后更新：

```bash
git pull
```

## 使用方法

1. 把待处理图片放进同一个文件夹。
2. 用「文本编辑」打开「批量生成参数.conf」，按需要调整参数。
3. 右键打开「开始批量随机生成.command」。
4. 在弹窗中选择图片文件夹。
5. 终端会显示当前图片、抽中的形变和运镜。
6. 完成后自动打开输出文件夹。

工具只读取所选文件夹的**第一层图片**，不会递归处理子文件夹。

## 输出说明

输出目录创建在所选图片文件夹内：

```text
随机微动视频-YYYYMMDD-HHMMSS/
├── 001-原图名-形变名+运镜名.mp4
├── 001-原图名-形变名+运镜名.mp4
├── 002-原图名-形变名+运镜名.mp4
└── ...
```

默认视频规格：

| 项目 | 默认值 |
|---|---:|
| 分辨率 | 1080 × 1920 |
| 比例 | 9:16 |
| 时长 | 3 秒 |
| 帧率 | 30 fps |
| 编码 | H.264 |
| 音频 | 无 |

横图或其他比例图片会按 9:16 居中放大并裁切，原图边缘可能被裁掉。

## 35 种随机组合

### 7 种运镜

1. v1.3 手持基准
2. v1.3 快门基准
3. 柔和手持
4. 稳定推近
5. 轻微上提
6. 轻微下压
7. 轻微左漂

### 5 种形变

1. 纵向形变
2. 横向形变
3. 仿射倾斜
4. 轻微侧倾
5. 镜头畸变呼吸

每个视频只使用 **1 种运镜 + 1 种形变**。五种形变不会同时叠加在同一个视频中。

## 配置文件说明

配置文件是「批量生成参数.conf」。

只修改等号右边的值，不要删除变量名，不要加百分号，不要使用中文标点。例如：

```conf
VIDEOS_PER_IMAGE=2
DURATION=3
FPS=30
QUALITY=18
SUPERSAMPLE=2
```

### 生产参数

| 参数 | 默认值 | 有效/建议范围 | 作用 |
|---|---:|---:|---|
| `VIDEOS_PER_IMAGE` | 2 | 有效 1～35 | 每张图片生成多少条不重复组合视频 |
| `DURATION` | 3 | 建议 2.5～3 | 视频时长，单位为秒 |
| `FPS` | 30 | 有效 24～60；建议 30 | 帧率。提高到 60 会明显增加处理时间和文件体积，不会自动让运动更真实 |
| `QUALITY` | 18 | 建议 17～20 | H.264 CRF 清晰度。数字越小越清晰、文件越大 |
| `SUPERSAMPLE` | 2 | 有效 1～4；建议 2 | 运镜内部超采样倍数。1 更快但更容易出现像素台阶；3～4 更慢且更占内存 |

### 形变参数

参数名中的 `PERCENT` 表示百分比，但配置值**不要写 `%`**。

| 参数 | 默认值 | 建议范围 | 作用与风险 |
|---|---:|---:|---|
| `VERTICAL_STRETCH_PERCENT` | 0.5 | 0.2～0.8 | 纵向轻微拉伸幅度。当前使用亚像素透视插值；过大会让人物脸型和商品比例明显变化 |
| `HORIZONTAL_STRETCH_PERCENT` | 0.5 | 0.2～0.6 | 横向轻微拉伸幅度。过大会产生明显“变宽/变窄”的特效感 |
| `SHEAR_PERCENT` | 0.8 | 0.2～0.8 | 水平仿射倾斜强度。默认值位于建议上限；人物近景觉得明显时优先降到 0.4 |
| `ROLL_DEGREES` | 0.25 | 0.1～0.35 | 镜头轻微侧倾角度，单位为度。过大会像人为旋转转场 |
| `LENS_BREATHING` | 0.012 | 0.003～0.012 | 径向镜头畸变呼吸强度。默认值位于建议上限；直线背景弯曲明显时降到 0.006 |

当前推荐基准：

```conf
VIDEOS_PER_IMAGE=2

DURATION=3
FPS=30
QUALITY=18
SUPERSAMPLE=2

VERTICAL_STRETCH_PERCENT=0.5
HORIZONTAL_STRETCH_PERCENT=0.5
SHEAR_PERCENT=0.8
ROLL_DEGREES=0.25
LENS_BREATHING=0.012
```

### 调参原则

- 一次只改一个参数，否则无法判断是哪项造成改善或退步。
- “动得明显”不等于“更像 Live Photo”；人物近景尤其要克制。
- 出现拉脸、压扁或背景直线弯曲时，先把对应形变参数减半。
- 出现不连贯时，不要先提高 FPS；先恢复 `SUPERSAMPLE=2`。
- 批量生产前先拿 1～2 张代表图片小规模测试。

## 常见问题

### Mac 提示“无法验证开发者”或建议移到废纸篓

1. 不要移到废纸篓，点击完成。
2. 打开「系统设置 → 隐私与安全性」。
3. 找到被阻止的脚本，点击「仍要打开」。
4. 或在 Finder 中右键脚本，选择「打开」。

### 双击脚本没有反应

在仓库目录执行：

```bash
chmod +x 首次安装.command 开始批量随机生成.command
```

然后重新右键打开。

### 提示尚未安装 FFmpeg

右键运行「首次安装.command」。如果安装失败，检查网络后重试。

如果已经安装 Homebrew，也可以在终端执行：

```bash
brew install ffmpeg
```

### 提示找不到配置文件

「开始批量随机生成.command」和「批量生成参数.conf」必须放在同一个文件夹，不能只移动其中一个文件。

### 提示没有可处理图片

确认图片位于所选文件夹第一层，并且扩展名是 JPG、JPEG、PNG、HEIC 或 WebP。

### 输出视频看起来很假

这个工具的本质是静态图运镜和轻微几何形变。人物、头发、衣服和被子不会产生真实动作。它更适合短暂的 2～3 秒实况感、产品特写和环境图，不应该替代真正的人物动态视频。

### 输出数量怎么算

```text
输出视频数 = 成功读取的图片数 × VIDEOS_PER_IMAGE
```

例如 20 张图片、每张生成 2 条，正常情况下会输出 40 条视频。

## 安全说明

- 工具不会删除或覆盖原图。
- 中间缓存使用系统临时目录，处理结束后自动清理。
- 输出写入新建的时间戳文件夹。
- 首次安装脚本会从 Homebrew 官方安装地址安装 Homebrew，并通过 Homebrew 安装 FFmpeg。
